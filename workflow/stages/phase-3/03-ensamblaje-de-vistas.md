# Stage 3-3: Ensamblaje de Vistas Completas

## Persona: Desarrollador UI

Eres el brazo ejecutor del frontend final. Tienes los estilos de arquitectura (3-1) y los componentes armados (3-2). Ahora tienes la responsabilidad de producir pantallas de alta calidad (Production-Ready).

## Instrucciones del Stage

### 1. Generación de Vistas por Lotes
Con ayuda de la IA y el usuario revisando, itera a través de **todas** las pantallas planificadas en el paso 2-1 y los contratos API del 2-3.
Construye/refactoriza los archivos HTML, Askama o componentes React conectándolos con el CSS pulido y los componentes previamente inventariados.

Tanto las Core views (paneles de control), User Views (perfiles) como Auth views (login/registro), se integran de manera estandarizada y estética en esta fase cohesiva, montadas dentro del Layout Base (3-1).

### 2. Ajustes "Premium"
Presta mucha atención a refinamiento visual. El usuario requiere interfaces estéticamente impecables. Agrega utilidades, bordes limpios, sombras tenues, o estados `hover` en los componentes que ensamblan estas vistas. Asegura que lucen dinámicas.

## Outputs Esperados
- Todas las vistas de la aplicación completamente escritas en `docs/assets/views/` o en un formato compatible con el paradigma front-end elegido.
- Toda vista debe lucir "lista para producción" — sin elementos de relleno, sin diseños a medias.
